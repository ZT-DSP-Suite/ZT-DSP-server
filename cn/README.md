# ZT-DSP 服务器版（开发中）

> 本仓库是 ZT-DSP **服务器版**的占位仓库，尚未开始实现。

## 为什么需要服务器版

当前客户端版（仓库 `ZT-DSP-client`）是直连模型：通信双方必须各自可达——**两端都需要公网 IP 或其他可直连方式**（端口映射、IPv6、隧道等）。这在小规模、互信的朋友之间可用，但不适合以下场景：

- 一方位于 NAT 之后且无法做端口映射；
- 需要异步投递（对方离线时消息仍能送达）；
- 需要多方群组、身份目录或跨组织联邦；
- 需要在不暴露彼此 IP 的前提下建立连接。

服务器版的目标是在**不削弱现有端到端安全属性**的前提下补齐上述能力，并保持与客户端版协议的兼容与可互操作。

## 状态

- 阶段：**规格设计前**
- 本仓库当前只包含占位说明与许可。功能范围、协议扩展、威胁模型与安全边界将在设计文档确定后逐步填入。
- 服务器**不得**成为明文可见点：任何中继设计都必须保持端到端加密，服务器应仅能看到路由所需的最小元数据。
